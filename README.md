# 🐸 FROGGER.REWIND

A Frogger-inspired game developed in Unity and C# during a one-week game development competition.

## Features

- Procedurally generated platforms and obstacles.
- Pathfinding to ensure every level is solvable.
- Visual indicators for safe and dangerous elements.
- Optimized level generation for reliable performance.

## About

The main challenge was generating random levels while guaranteeing that each level could be completed. This involved implementing pathfinding, level validation, and performance optimizations.

The project was developed collaboratively, with a focus on rapid iteration, version control, and testing.
